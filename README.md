# TravelStay - Travelling Website

This project is a simple Airbnb-type travelling website created for Cloud Computing subject. The website shows travel stays like hotels, resorts, apartments and allows users to search destinations.

## Features

- Travel stay listings
- Search functionality
- Responsive card layout
- Book Now button
- Simple UI design
- Cloud deployment ready

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub
- Vercel (Cloud Platform)
